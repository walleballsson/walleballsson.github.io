University Staff Database github.com/walleballsson/datalagring →
MySQL · Java · KTH course IV1351 Database Technology

A three-lab project modelling teaching staff, course instances, workload, and salary at a university. Schema design, analytical SQL queries, and a Java CLI app with transaction control.

  • 12-table normalized schema (3NF) - employee, department, course, workload, salary history
  • OLAP queries pivoting worked hours by activity type per teacher per course
  • Business rule: max 4 course instances per teacher per study period
  • Enforced business constraints both with SQL triggers and transaction-safe locking using SELECT FOR UPDATE
  • Java CLI with manual commit/rollback and PreparedStatement throughout
-- Hours per teacher per course instance
SELECT CONCAT(p.first_name, ' ', p.last_name) AS teacher,
       SUM(wl.work_hours * ta.factor)          AS total_hours
FROM workload wl
JOIN planned_activity pa ON wl.planned_activity_id = pa.planned_activity_id
JOIN teaching_activity ta ON pa.activity_id = ta.activity_id
JOIN employee e ON wl.employee_id = e.employee_id
JOIN person p   ON e.person_id = p.person_id
GROUP BY p.person_id;
